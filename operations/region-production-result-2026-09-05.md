## 지속 갱신 및 수동 처리

정규화 워커는 기존 화장실의 원본 주소·좌표 지문을 비교하고 변경분을 같은 Java 엔진으로 재판정한다. 좌표/주소가 달라진 이전 결과는 `current_toilet_region` 조회에서 즉시 제외되고, 비동기 판정 완료 후 검증된 결과만 다시 노출된다. 주소 오타 수정만으로 기존 좌표를 재생성하지 않는다.

**운영 활성화 완료:** 12:39:41 KST 기동, 12:40:45 첫 자동 실행 완료. 53,582건 전체 조회·checkpoint skip 53,582건·처리/외부 호출/좌표 변경 0건을 확인했다. 최종 원본 대조와 KST 판정 시각 검증도 모두 통과했다. `BATCH_REGION_ENABLED=true` 및 예산/간격/상한은 GitHub repository variables에 반영해 이후 배포에도 유지한다.

초기 분석의 API 예약 기록은 원본 아카이브에 보존한다. 운영 워커에는 결과·역지오코딩 캐시만 이관하며, 운영 워커의 신규 호출은 별도 영속 일일 1,000회 예산으로 관리한다. 호출 간격 1초, 한 회 최대 100건, 5분 fixed-delay, 시작 후 1분 지연이다. 정상 새 작업이 끝난 후 다음 간격이 시작되므로 정확한 실시간 갱신을 보장하지는 않는다.

수동 검토 309건 및 좌표 없음 1,288건은 자동으로 정상 판정하거나 원본 좌표를 만들지 않는다. [검토 집계](region-full-manual-review-2026-09-05.md)와 DB의 상태/사유/근거 JSON/판정 이력으로 확인한다. 전용 관리자 화면은 이 적재 배포 이후 별도로 배포했으며 [관리자 검토 배포 보고서](region-admin-review-release-2026-09-05.md)에 기록했다.

## 남는 주의점

- 같은 시군구 안의 잘못된 시설 위치는 지역 일치만으로 검출할 수 없다.
- B/H 시군구 코드 충돌 7건은 `REVERSE_FAILED`와 사유를 유지한다. 자동 확정 금지.
- 외부 API 오류·일일 예산 소진·동시 수정은 검토/재개 대상으로 남긴다.
- 승인 좌표의 주소는 도로명·지번을 구분해 저장한다. 도로명 없는 곳에 지번을 도로명 컬럼으로 대체하지 않는다.
- 롤백 시 워커를 먼저 끄고 이전 이미지로 복귀한다. 파생 테이블/이력을 자동 삭제하거나 원본 주소·좌표를 일괄 덮어쓰지 않는다.
